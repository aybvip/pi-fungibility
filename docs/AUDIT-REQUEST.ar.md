# التدقيق المستقل — الحالة، النطاق، وكيفاش تدير واحد

🌍 [English](AUDIT-REQUEST.md) · **العربية**

> **بالصريح: هذا المستودع ما خضعش لتدقيق مستقل.**
> هو **موثّق ذاتيًا وقابل للتكرار الكامل**، وهذا **موش** نفس الشي كيما تدقيق طرف ثالث.
> هذا الملف يقول بالضبط شنوّة يعني هذا، وشنوّة يلزم يدقّق فيه المدقّق، وكيفاش تكرّر كل شي.

---

## 1. الحالة (بصراحة، من البداية)

| السؤال | الجواب |
|---|---|
| مدقّق مستقل من طرف ثالث؟ | ❌ **لا** |
| مراجعة أكاديمية/مهنية رسمية؟ | ❌ **لا** |
| قابل للتكرار من أي واحد (مصادر + كود)؟ | ✅ **نعم** |
| اختبارات آلية لـ**منطق الأداة**؟ | ✅ **نعم** — [`examples/self-test.mjs`](../examples/self-test.mjs) + [CI](../.github/workflows/self-test.yml) |
| نموذج تنفيذي + فحص خصائص؟ | ✅ **نعم** — [`examples/model-check.mjs`](../examples/model-check.mjs) (بلا شبكة، 2000 بذرة) |
| تحقّق استنفادي (محدود)؟ | ✅ **نعم** — [`examples/exhaustive-check.mjs`](../examples/exhaustive-check.mjs) (كل 1452 تاريخ في مجال منتهي) |
| نجاح الاختبارات يثبت البرهان الرياضي كامل؟ | ❌ **لا** — الاختبارات تفحص **الأداة**، موش **البرهان** |

> ⚠️ **ما تقراش «الاختبارات نجحت» على أنّه «مدقّق».** الفحص الآلي يتحقّق من سلوك سكربت واحد على
> معاملة واحدة. التدقيق هو مراجعة **بشرية** للـ**ادّعاءات والبرهان والكود مع بعض**.

---

## 2. شنوّة يعني «تدقيق مستقل» هنا

المدقّق هو **طرف ثالث** (موش المؤلف) يفحص، **بنوايا جدالية (adversarial)**، إنّ:

1. **الادّعاء مصاغ بدقّة** — قبل أي فحص: هل الادّعاء قابل للتعريف أصلًا؟
   (نعم: *«معاملة Pi الأصلية على شبكة Pi Mainnet لا تحمل معلومة قابلة للملاحظة تحدّد تاريخ تعدين كل وحدة على حدة.»*)
2. **البرهان سليم** — كل خطوة في [`SCOPE.ar.md`](SCOPE.ar.md) §7 / [`PROOF.ar.md`](../PROOF.ar.md) ماشية،
   و**بلا فرضية مخفيّة**.
3. **المصادر تقول اللي منسوب ليها** — كل اقتباس في [`SOURCES.ar.md`](SOURCES.ar.md) مطابق للوثيقة
   الرسمية (docs.minepi.com، ورقة MiCA، توثيق Platform API).
4. **الكود يعمل اللي يدّعي** — للقراءة فقط، بلا نداءات مخفيّة، وخرجه يطابق نتيجة محسوبة يدويًا.
5. **النطاق محترم** — ما فماش خلط بين الادّعاءات **A / B / C** (لتحت)، وما فماش إيحاء بأكثر من الادّعاء.

فقط (1)–(5) **مع بعض**، من غير المؤلف، يعتبروا تدقيق. وحتى واحد منهم ما مدّعى إنّه صار من طرف ثالث.

## 4. كرّر كل شي بنفسك (≈ 5 دقائق)

يحتاج فقط **Node 18+** (بلا npm، بلا تبعيات) واتصال بالشبكة.

```bash
git clone https://github.com/aybvip/pi-fungibility
cd pi-fungibility

node examples/self-test.mjs          # 8 اختبارات وحدة (evaluate) + 3 فحوصات أونلاين طرف-لطرف
node examples/model-check.mjs        # نموذج سجلّ + فحص خصائص بلا شبكة (2000 بذرة، حتمي)
node examples/exhaustive-check.mjs   # فحص استنفادي محدود بلا شبكة (كل 1452 تاريخ)
node examples/coin-id-check.mjs      # ما فماش معرّف لكل micro-π على السجلّ
node examples/provenance-check.mjs   # حساب حيّ باستقبالات كثيرة، ورصيد رقم واحد
node examples/mixing-check.mjs       # معدَّنة + مشرية -> رصيد واحد -> دفعة بلا مصدر
```

من بعد اقرا، **مقابل الكود**، الادّعاءات في `SCOPE.ar.md` / `PROOF.ar.md`. كل شي يدّعيه المستودع عن
البروتوكول هو إمّا **مصدر رسمي مقتبس** أو **سكربت node بسيط** شغّلتو توّا.

> 🔧 السكربتات مقصود صغار وبلا تبعيات باش يتقراو **سطر بسطر** —
> شوف [`SECURITY.ar.md`](../SECURITY.ar.md) لضمانة القراءة فقط (بلا محفظة، بلا مفاتيح، بلا توقيع).

## 5. حدود معروفة (قائمة المدقّق)

- **البرهان الشكلي موش متحقّق آليًا في مساعد إثبات (proof assistant).** §7 حجّة مكتوبة، موش ملف
  Lean/Coq. نوفّروا **نموذج تنفيذي + فحص خصائص** ([`examples/model-check.mjs`](../examples/model-check.mjs)،
  2000 بذرة) و**فحص استنفادي محدود** ([`examples/exhaustive-check.mjs`](../examples/exhaustive-check.mjs)،
  كل 1452 تاريخ في مجال منتهي) — بجوجهم بلا شبكة. قويّين، أمّا **محدودين**؛ ومازال **موش** نفس الشي كيما
  صياغة شكلية موثّقة.
- **المصادر بتاريخ نشرها.** إذا Pi Network بدّلت البروتوكول أو توثيقها بدّل، أعد التحقّق (شوف
  [`SOURCES.ar.md`](SOURCES.ar.md) للتواريخ/الروابط).
- **الأمثلة الحيّة تابعة للشبكة.** تستعلم `https://api.mainnet.minepi.com`؛ حساب/معاملة بعينها تنجّم
  تتبدّل مع الوقت. **المخرجات النموذجية** محفوظة كلمحات (`examples/*-output.txt`) — **الطريقة**، موش
  الأرقام، هي المقصودة.
- **«أصلية» ≠ «مغطّاة».** شوف الادّعاء C — مقصود برّا النطاق.
- **بلا ضمان أمني.** هذا تحليل، موش نصيحة مالية ولا أمنية ([`DISCLAIMER.ar.md`](../DISCLAIMER.ar.md)).

## 6. لقيت مشكلة؟ بلّغ عليها

الأخطاء مرحّب بيها — هذا هدف مستودع عمومي قابل للتكرار.

- افتح **issue** مع: الادّعاء المعني (A/B/C)، المصدر أو الأمر، والمُشاهد مقابل المتوقّع.
- إذا تعلّق الأمر بسلوك **الكود**، زيد سطر الأمر الكامل والخرج كامل.
- إذا **اقتباس** منسوب بالغلط، اربط المصدر الرسمي باش يتصلّح.

> **المعيار اللي نحاسبوا بيه رواحنا:** *دقّق، ما تثقش* — حتى هذا المستودع نفسه.
> حتى يدير طرف ثالث هذا، التسمية الصحيحة هي **«موثّق ذاتيًا، قابل للتكرار، موش مدقّق مستقلًا.»**
